# Claude Code Instructions

Read [AGENTS.md](./AGENTS.md) for the full repository guidelines: architecture, directory layout, code conventions, development commands, and configuration reference.

## Quick Reference

- **Rust backend**: `sts/` - Cargo workspace with 3 binaries and 4 library crates
- **OCR service**: `sts-ocr/` - Python Flask app (single file)
- **Frontend**: `sts-ui/` - Angular 19 standalone app
- **Experiments**: `sts-ocr-playground/` - Rust + Python OCR prototypes

## Build & Run

```sh
# Rust backend
cd sts && cargo build                          # check compilation
cd sts && cargo run --release --bin webapp      # web API on :3000
cd sts && cargo run --release --bin axsys-sol-bot  # bot on :3001

# Frontend
cd sts-ui && npm install && ng serve           # dev server on :4200

# Infrastructure
docker compose -f sts/docker-compose-main.yaml up -d  # PostgreSQL + webapp
docker compose -f sts-ocr/docker-compose.yaml up -d   # OCR on :6999
```

## Key Patterns

- **Async**: Tokio runtime, `mpsc` channels for inter-task communication, `Arc<RwLock<>>` for shared state
- **Database**: Diesel 2.x async with PostgreSQL, `Arc<Mutex<AsyncPgConnection>>`
- **Logging**: `tracing` crate with daily rolling file appender
- **Error handling**: `Box<dyn Error + Send + Sync>` at boundaries, `.unwrap()` in DB ops
- **Config**: All via `.env` files loaded with `dotenv` — see `sts/.env.example`
- **Auth**: EVM wallet signature verification, JWT with Ed25519 (EdDSA)
- **Encryption**: AES-256-GCM via `ring` crate for wallet private key storage

## Before Editing

- Rust lints are suppressed (`#![allow(clippy::all)]`) — do not assume clippy compliance
- No automated tests exist for the Rust backend
- `sts/bin/webapp/src/db/schema.rs` is auto-generated by Diesel CLI — do not edit manually
- Environment variables are required at runtime — check `.env.example` before adding new ones
